# Changelog

## v1.4.0

### Added
- Support for rendering meshes as Triangles, Lines and Points.
- Support for rendering Triangles and Wireframe simultaneously.
- Independent render mode flags using bitmask.
- Wireframe rendering with custom color.
- Bitmap-based terrain generation.
- Dynamic vertex buffer update.
- Optimized line index generation.
- Runtime mesh vertex update.
- Vertex color / uniform color switching.

### Improved
- Mesh rendering architecture.
- Buffer management.
- Rendering performance.
- Terrain generation pipeline.

### Fixed
- Wireframe rendering issue.
- Vertex update synchronization.
- Index buffer switching.
